# 个人研习记录

输入标题、栏目和正文，保存后可回看版本。离开前导出需要保留的记录；清除浏览器数据会移除本机副本。

## 工作台

从只有未绑定textarea的展示样例变为本机文字记录工作台：示例、栏目、搜索、新建/保存、刷新恢复、10次正文旧版本、JSON/Markdown导出、受校验的JSON导入与删除。

## 数据、异常与资源边界

最多50条/5MB，单正文20,000字符，单记录 JSON 导入上限 2 MiB，可容纳 10 个历史版本和当前正文。未保存切换/刷新提示，异常存储保留且禁止覆盖。仍为文字记录与展示，不执行排盘/业务推断，组件公共API保持。

## 历次验证

类型/构建、独立打包消费者/SSR、源清单（提交后刷新）、桌面/390px/320px保存刷新/旧版本/下载。

## 本地启动

```sh
npm ci && npm run dev
# 127.0.0.1:18872
```


复核补齐：记录正文按材料、观察/问题、下一步分组展示为结构化摘要；正文编辑与旧版本载入后重新计算，JSON导出同时包含原文和摘要，导入只采信校验后的原文，不采信外部摘要。分组为文字规则处理，不生成推断或排盘。

## 工作区与窄屏操作

桌面采用正文与记录依据双栏，摘要、正文预览和旧版本集中在侧栏。窄屏按需展开摘要与版本；从记录列表打开后收起列表并聚焦当前标题。正文、导入、保存及版本保全规则保持一致。
